# explain decide — 현재 선택을 판단할 수 있게 보인다

1. 지금 정할 것을 확인한다. 없으면 결론과 근거만 짧게 보고한다.
2. 파일:줄, 실행 결과, 파트너 답 원문에서 근거를 모은다. 미확인은 따로 밝힌다.
3. 결론과 정할 것, 추천 이유를 먼저 보인다. 실제 대안이 있으면 차이·근거·위험을 비교한다. 두 안을 채우기 위해 가짜 대안을 만들지 않는다.
4. 구조 차이는 그림으로, 병렬 비교는 표로 보일 수 있다. 단순한 선택이면 문장만으로 답한다.
5. 어떤 미확인이 선택을 바꿀지와 확인 방법을 밝힌다. 사용자 결정 없이 요구·설계를 확정하거나 코드로 옮기지 않는다.

채팅에도 선택의 차이와 추천 이유를 보인다. 긴 근거는 보고서에 둔다. 리뷰라면 요구별 상태·증거가 비교표를 대신할 수 있다. 사용자의 선택 이후 기록 반영은 요청 범위에 따라 메인 세션이 한다.
