# explain decide — 정하게 하는 보고

## 절차
1. 이 보고로 사용자가 정할 것 하나를 먼저 정한다. 정할 것이 없으면 "없음" 이고 보고는 짧아진다.
2. 근거를 모은다: 파일:줄, 명령과 결과, 담당자 답(Q# 원문). 근거 없는 주장은 "모르는 것" 칸으로 보낸다.
3. 아래 여섯 칸을 이 순서로 쓴다.

## 여섯 칸
1. `결론:` 한 문장.
2. `정할 것:` 하나와 추천, 추천 이유 한 문장.
3. 그림 하나: 지금 상태나 선택지의 구조.
4. 비교 표 하나: 열 이름을 고정한다. 기본은 선택지 / 왜 / 대안 / 위험. 리뷰면 R# / 상태 / 증거.
5. 근거: 한 줄에 출처 하나.
6. 모르는 것: 확인 안 된 것과 확인 방법. 추정은 A# 로 적고 docs/assumptions.md 에 옮길지 묻는다.

## 종류별 그림
| 보고 | 그림 |
|---|---|
| 도메인 조사 | 세 칸 지도: 아는 것 / 담당자 확인 필요 / 모름 |
| 자료 실측 | 열 표가 그림을 대신한다 |
| 설계 대화 | 상자와 화살표: 화면 → API → 자료, 파일 이름 포함 |
| 리뷰 | R# 표가 그림을 대신한다 |
| 제출 전 | 세 칸: 동작하는 것 / 약한 곳 / 다음 검증 |
