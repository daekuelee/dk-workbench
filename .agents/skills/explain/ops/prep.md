# explain prep — 후속 서술형 대비

후속 문항은 AI 없이 5분씩 답한다 (SITUATION.md). 이 op 는 사용자가 혼자 말할 수 있게 재료를 한 장에 모은다. 사용자가 이 파일을 보고 말해 본 뒤에는 열지 않고 답한다.

## 절차
1. docs/plan.md, docs/questions.md, docs/worklog.md, docs/limits.md(있으면), git log 를 읽는다.
2. 앱을 한 번 돌려 요청 하나를 따라간다.
3. docs/reports/prep.md 를 아래 순서로 쓴다. 50줄 이하.

## 순서
1. 뼈대 한 문장과 그림 하나 (understand 의 2, 3 칸).
2. 결정 셋: 무엇을 정했나 / 왜 (출처 Q# 나 실측) / 버린 대안.
3. 약점 셋: 어디서 깨지나 / 깨지면 무엇이 일어나나 / 무엇으로 확인하고 고치나.
4. 바뀐 요구: 무엇이 언제 바뀌었고 어디를 고쳤나.
5. 예상 질문 여섯: "왜 그렇게 판단했나", "무엇을 했나", "장애나 변경이 오면 어떻게 하나" 꼴. 질문마다 답의 재료가 있는 줄(파일:줄)을 붙인다. 답 문장은 쓰지 않는다. 답은 사용자가 쓴다.
6. 답 틀: 전제 확인 → 한 일과 판단 → 약점과 위험 → 다음 검증.
