# explain understand — 질문한 대상을 이해시킨다

질문에 직접 답하고, 부품들이 어떤 일을 함께 하는지 보이게 설명한다. 아래 재료 중 질문에 필요한 것을 고른다. 짧은 개념 질문은 짧게 답한다.

## 대상을 확인한다
- 설명할 파일·함수·동작을 읽는다. 코드와 동작의 근거는 파일:줄로 붙인다.
- 실행 흐름을 물었다면 요청 하나나 자료 한 줄을 실제로 따라간다. 실행할 수 없으면 읽어서 확인한 경로와 실행하지 못한 부분을 구분한다.

## 설명에 쓸 재료
- 직접 답과 뼈대: 부품 나열로 끝내지 않고 이 대상이 무엇을 받아 무엇으로 바꾸는지 설명한다.
- 그림: 관계가 복잡하면 파일 이름과 경계를 상자·화살표로 보인다.
- 실제 값: 어디에서 값이 어떻게 바뀌는지 요청 하나로 따라간다.
- 낯선 부품: 필요한 용어를 정의하고, 도움이 되면 anchors의 C++·엔진 비유와 차이를 쓴다.
- 선택 이유: 실제 plan·파트너 답의 근거가 있으면 연결한다. 알려지지 않은 이유는 만들어 쓰지 않는다.

사용자가 묻지 않은 앱 전체나 문법 강의로 늘리지 않는다. 더 볼 부분이 있어도 현재 답에 필요한 정도만 표시한다. 출력·기록은 SKILL을 따른다.
