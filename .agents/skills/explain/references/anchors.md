# 비유 기준표 — 웹·서비스 개념을 C++·엔진 개념에 빗댄다

읽는 사람은 C++ 엔진 개발자다 (PROFILE.md). 낯선 개념은 이 표의 가장 가까운 줄로 먼저 빗대고, 다음 문장에 공식 용어를 쓴다. 표에 없으면 같은 결로 새로 빗대되, 다른 점 하나를 꼭 같이 쓴다.

| 웹·서비스 개념 | 빗댈 것 | 다른 점 |
|---|---|---|
| HTTP 서버, 라우트 | 메시지 종류별로 핸들러를 고르는 디스패치 테이블 | 요청마다 새로 들어오고 연결 상태가 없다 |
| 요청 핸들러 함수 | 이벤트 콜백 | 반환값이 곧 응답 본문이 된다 |
| JSON 응답 | 직렬화된 구조체 | 타입 정보가 없어서 받는 쪽이 모양을 믿어야 한다 |
| 브라우저의 fetch | 비동기 I/O 요청과 완료 콜백 | 결과는 Promise 로 온다 |
| HTML 한 장 + JS | UI 레이어, 매 프레임이 아니라 이벤트 때만 다시 그린다 | DOM 이 상태를 들고 있다 |
| 서버 시작 때 CSV 를 메모리로 읽기 | 초기화 때 리소스 로딩 | 파일이 바뀌면 재시작해야 반영된다 |
| 집계 함수 | CPU 쪽 전처리 패스 | 요청마다 다시 돌 수 있다 |
| 미들웨어 | 렌더 패스 체인의 앞뒤 훅 | 순서가 결과를 바꾼다 |
| JSON 파일이나 SQLite 저장 | 세이브 파일 | 동시에 두 요청이 쓰면 깨질 수 있다 |
| 앱 안의 LLM 호출 | 원격 블로킹 호출인데 결과가 매번 조금씩 다르다 | 같은 입력에 같은 출력을 기대할 수 없어서 케이스로 검증한다 |
| 프롬프트 | 셰이더 파라미터처럼 동작을 바꾸는 입력 | 컴파일 오류 없이 조용히 틀린다 |
| 환경 변수와 API 키 | 빌드 설정과 비밀 값 | 코드에 박으면 수집 자료에 남는다 |
| 0.0.0.0 바인딩 | 모든 네트워크 인터페이스에서 받기 | 127.0.0.1 이면 미리보기 탭이 못 들어온다 |
| verify.sh | 회귀 테스트 묶음 | 기대값을 앱 밖에서 가져와야 의미가 있다 |
