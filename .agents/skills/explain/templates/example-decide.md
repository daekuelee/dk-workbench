결론: 자료는 73행이지만 중복 1행과 형식이 섞인 값 12개가 있어, 정리 규칙 셋을 정해야 숫자가 맞는다.
정할 것: 중복 ID 를 한 건으로 볼지 (추천: 한 건으로 본다, 같은 티켓이 두 번 뽑힌 것으로 보인다. 팀장 확인 전)

```text
아는 것                     담당자 확인 필요              모름
─────────────────────────   ─────────────────────────    ──────────────
73행, 7열                    중복 ID 1건의 뜻              자료 갱신 주기
status 대문자 4건            미래 처리일 12건의 뜻
"/" 날짜 8건                 기준일 = 오늘?
담당자 빈칸 9건
```

| 정리 규칙 | 왜 | 대안 | 위험 |
|---|---|---|---|
| status 를 소문자로 | 같은 상태가 둘로 세어진다 | 그대로 둠 | 없음 |
| 날짜 "/" 를 "-" 로 | 날짜 비교가 실패한다 | 그 줄을 버림 | 버리면 8건이 사라진다 |
| 중복 ID 는 첫 줄만 | 같은 티켓이 두 번 세어진다 | 둘 다 셈 | 팀장이 다르게 볼 수 있다 (A3) |

근거
- `python3 -c "..."` 로 센 결과: 73행, ticket_id 중복 1건 (T-0031).
- status 값 분포: open 12, OPEN 4, in_progress 10, ...
- Q3 답: "시스템에서 뽑을 때 가끔 이상하게 나와요."
