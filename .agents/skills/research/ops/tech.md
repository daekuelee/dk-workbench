# research tech — 기능에 맞는 기술 선택의 근거를 구한다

1. 필요한 기능과 이번에 정할 것을 밝힌다. plan의 제약·현재 스택과 context의 확인된 환경을 읽는다.
2. `../references/sources.md`에 따라 필요한 출처를 고른다. 버전·지원 여부·정확한 사용법에 웹 확인이 필요하면 범위를 제안하고 허락을 받는다. 기존 스택으로 가능한지 먼저 본다. 실제 선택이 남아 있을 때 후보를 비교한다. 이미 결정한 것을 형식상 다시 비교하지 않는다.
3. 후보의 역할·차이·위험·설치 비용을 설명한다. 사용자가 이해하고 설명할 수 있는지도 고려한다.
4. 추천과 근거, 아직 확인하지 못한 것을 밝힌다. 사용법이 판단에 필요하면 공식 문서의 작은 예를 출처와 함께 보인다.

설치하지 않는다. 설치는 사용자가 선택하고 plan에 기록한 뒤 메인 세션이 한다. 새 프레임워크의 학습 비용과 설명하기 어려워지는 부분도 판단 재료다. 기록은 SKILL의 실행 주체별 규칙을 따른다.
