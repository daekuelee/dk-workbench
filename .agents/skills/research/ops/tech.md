# research tech — 무엇으로 만들까

## 절차
1. 만들 기능을 한 줄로 쓴다. plan.md 의 스택 칸을 읽는다. 이미 정한 스택 안에서 먼저 찾는다.
2. 후보를 둘이나 셋 찾는다. 표준 라이브러리, 이미 설치된 것, 새로 설치할 것 순서로 본다 (`pip list`, `python3 -c "import X"` 로 설치 여부를 확인한다).
3. 표를 쓴다: 후보 / 무엇 / 왜 / 대안과 비교 / 위험 / 설치 비용.
4. 추천 하나. 기준은 셋이다: 사용자가 설명할 수 있나, 설치가 적은가, plan 의 범위 안인가.
5. 가장 작은 사용 예 하나: 공식 문서 기준, 출처를 첫 줄에 쓴다. 10줄 이하.

## 하지 않는 것
- 설치하지 않는다. 설치는 사용자가 정하고 plan 에 적은 뒤 작업 세션이 한다.
- 새 프레임워크를 추천할 때는 버리는 것(학습 비용, 설명 못 하는 면적)을 같이 쓴다.
