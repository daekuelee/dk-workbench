# 판정 기록 (research)

새 판정은 맨 아래에 더한다. 날짜, 무엇이 틀렸나, 이제 어떻게 하나. 과거 기록은 보존하며 현재 행동은 SKILL과 ops를 따른다.

- (볼트에서 옮긴 기준) 소스를 열어 보지 않고 순위를 매기면 틀린다 → 자료와 파일은 직접 열고 센 결과만 쓴다.
- (볼트에서 옮긴 기준) 조사가 길어지면 만들기가 늦어진다 → 답 하나로 끝내고, 더 필요하면 다음 질문 하나만 제안한다.

- 2026-10-30 · 조사 분량과 산출물 개수가 판단보다 앞섰고 읽기 전용 역할에도 파일 쓰기를 요구했다 → 질문에 필요한 근거만 확인하고 기존 실측을 재사용한다. 역할은 답만 반환하고 메인 세션이 기록·채택을 맡는다.

- 2026-10-30 · 사용자 요청: 웹 크롤링 전에 먼저 묻고 모델 지식과 웹 중 무엇을 쓸지 판단해야 한다 → sources.md에 출처 선택·웹 허락·검색 후 원문 확인 절차를 둔다. 같은 질문의 허락은 재사용하고 역할은 미승인 웹 요청을 메인에 돌려준다.

- 2026-10-30 · 사용자가 시험의 시간·토큰 비용 때문에 웹을 예외적으로 쓰기를 원함 → 기본은 로컬 근거와 모델 지식이며, 현재 결정을 바꿀 중요한 미확인만 웹으로 제안한다. 허락한 관련 원문 부분만 읽고 불필요한 수집은 하지 않는다.
