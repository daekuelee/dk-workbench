# 출처 등급

| 출처 | 믿을 만한가 | 쓰는 법 |
|---|---|---|
| 파트너 답 (Q#) | 가장 높다. 이 과제의 정답이 여기 있다 | 원문을 인용한다 |
| 작업 폴더 파일 (README, 자료) | 높다. 다만 자료는 지저분할 수 있다 | 파일:줄, 센 명령과 결과 |
| 웹 (공식 문서) | 기술은 높고, 도메인은 이 팀과 다를 수 있다 | URL, "(확인 전)" |
| 모델 지식 | 그럴듯하지만 이 팀과 다를 수 있다 | "(확인 전)", 확인 질문으로 바꾼다 |

- 믿을 만한가와 쓸모 있나는 다른 축이다. 믿을 만해도 이 과제의 판단을 바꾸지 않으면 쓰지 않는다.
- 도메인 주장은 파트너가 확인하기 전까지 구현의 근거가 되지 않는다. 구현해야 하면 docs/assumptions.md 에 A# 로 적고 코드에 `# A#` 를 남긴다.
