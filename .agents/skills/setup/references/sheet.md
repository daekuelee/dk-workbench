# 1단계 — docs/setup.md
1. 상황 시트: 칸 / 내용 / 출처(README 줄). 없으면 "빈칸".
   칸: 역할, 현업 파트너, 실제 사용자, 쓰는 장면, 요청 원문, 숨어 있을 방식, 주어진 자료, 산출물, 시간, 모르는 것.
2. 문제 유형: archetypes.md 의 A~D 하나와 근거 줄. 섞이면 주 유형과 보조 유형.
3. 입력 형태: 사용자가 앱에 넣는 것(텍스트, 파일, 선택, 음성)과 앱이 읽는 자료(파일, 열, 행 수). 자료는 직접 센다.
4. 아키텍처 안 둘: 안 / 구조 한 줄 / 왜 / 위험 / 첫 동작본까지 시간. 추천 하나와 이유.
5. 핵심 질문 8개 이하: 빈칸을 채우는 질문을 사소한 것에서 깊은 것 순서로. 칸 이름을 붙인다. 해결 방법은 묻지 않는다. 마지막은 "잘한 예와 못한 예" 질문.
6. 검증 방식 초안: 유형의 검증 방식을 이번 과제 말로. 기대값의 출처를 쓴다.
