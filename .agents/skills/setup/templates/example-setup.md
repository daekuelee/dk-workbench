# 시작 준비 — 행사 참가 명단 확인

결론: 담당자는 참가 명단을 확인할 도구를 원하며, 자료와 실행 환경은 확인했지만 누가 언제 사용할지는 아직 모른다.
확인할 것: 아래 준비 내용에 고칠 사실이 있는지 확인한다.

## 명시된 사실
| 항목 | 내용 | 출처 |
|---|---|---|
| 요청 원문 | “참가 명단을 편하게 확인하고 싶어요.” | README:3 |
| 제약·마감 | 120분, 실행되는 결과물을 제출한다 | README:7 |
| 자료 | uploads/attendees.csv를 제공한다 | README:5 |

## 필요한 환경
| 항목 | 확인한 결과 | 근거·명령 |
|---|---|---|
| 언어 | Python 3.11을 사용할 수 있다 | python3 --version |
| 포트·실행 명령 | README에 지정돼 있지 않다. 구현할 때 정한다 | README:1 |

## 미확인
- 실제 사용자가 누구이고 언제 명단을 보는지 모른다. 첫 대화와 파트너 질문에서 확인한다.
- 자료의 중복 여부는 아직 세지 않았다. 명단을 어떻게 사용할지 정한 뒤 필요한 검사를 고른다.
