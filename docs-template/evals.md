# evals — 기대값은 앱 밖에서 온다 (데이터 직접 집계, 담당자 답과 예시)

## 확정 검사 (명령 하나로 확인 → verify.sh)
| R# | 검사 | 기대값 | 출처 |
|---|---|---|---|

## 판단 케이스 (AI 출력, 담당자 방식)
| E# | 입력 | 담당자가 원하는 반응 (말 그대로) | 출처 Q# | 결과 (S#) |
|---|---|---|---|---|

## 판정 방법
- 구조(필드, 길이, 금지어)는 스크립트로 본다.
- 품질은 케이스마다 "맞음 / 어긋남 + 이유 한 줄" 로 본다. 점수는 매기지 않는다.
