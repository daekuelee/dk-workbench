# 질문과 받은 답

## 내가 입력하는 곳

아래에 편하게 이어 붙인다. 표·번호는 필요 없다. 질문과 답을 여러 번 적거나 대화 전체를 붙여도 된다. 다른 파일에 모았으면 `원문 파일:`에 경로만 적어도 된다. 내 생각은 `내 메모:`로 구분한다. AI는 이 영역의 기존 원문을 지우거나 요약문으로 바꾸지 않는다.

질문: <내가 한 질문>
답변:
<받은 답 원문>

내 메모: <선택 — 내 생각이나 추가로 궁금한 것>
원문 파일: <선택 — 다른 로컬 파일에 모았을 때 경로>

## AI가 정리하는 곳

AI가 아래를 관리한다. 위쪽의 안내용 꺾쇠 문구는 실제 입력으로 처리하지 않는다. 원문은 위쪽 또는 지정된 파일에 보존하고 여기는 해석·연결·상태만 적는다.

### 풀어야 할 것

질문 후보마다 Q#와 질문, 왜 묻는지·바뀔 판단, 확인 대상·관찰 근거, 상태를 짧게 적는다. 상태는 후보/답 받음/추가 확인/해결/보류·제외 등을 쓸 수 있다. 보류에는 다시 확인할 시점·방법, 제외에는 이유를 남긴다. 사용자가 Q#를 직접 붙일 필요는 없다.

### 답 반영 기록

Q#별로 원문 위치, 확인한 사실, AI 해석·남은 빈 곳, 반영한 R#/A#를 연결한다. 사용자 메모와 파트너 답은 구분한다. 같은 답을 다시 받으면 중복 반영하지 않는다.
