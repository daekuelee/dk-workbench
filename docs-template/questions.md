# 질문과 받은 답

## 내가 입력하는 곳

read가 이번 과제의 질문·이유·확인 대상을 Q별로 미리 채운다. 사용자는 질문을 옮겨 적지 않고 해당 Q의 `답변:` 아래에 원문을 붙이면 된다. 파트너에게는 핵심 질문 하나씩 전달하되, 답 여러 개를 모아 fill에 한 번에 반영할 수 있다. AI 후보는 실제 전달한 질문이나 받은 답으로 취급하지 않는다.

### 먼저 확인할 질문

#### Q1
질문: <AI가 현재 큰 판단에 필요한 구체적인 질문을 채운다>
왜 묻나: <알게 될 업무 사실과 답에 따라 바뀔 판단>
확인 대상·근거: <파트너 / 사용자 / 자료 / Helper, 현재 이해 또는 출처>

답변:
<여기에 받은 답 원문을 붙인다>

내 메모: <선택 — 내 생각이나 추가 질문>

### 답을 보고 이어갈 질문

<필요한 후보가 있으면 AI가 같은 Q 형식으로 추가한다. 언제 왜 확인할지 밝히고, 고정 개수나 모든 예외를 채우지 않는다.>

### 내가 따로 한 질문·추가 대화

질문: <선택 — AI 후보 외에 직접 물은 질문>
답변:
<받은 답 원문 또는 추가 대화 전체>

내 메모: <선택>
원문 파일: <선택 — 다른 로컬 파일에 모았을 때 경로>

## AI가 정리하는 곳

Q#별 상태, 확인된 사실·해석·남은 빈 곳, 원문 위치와 R#/A# 연결을 관리한다. 질문과 이유를 여기에 다시 복제하지 않는다. 보류에는 확인 시점·방법, 제외에는 이유를 남긴다. 답을 받았다고 쟁점이 해결됐다고 단정하지 않는다.

AI는 위쪽에 새 질문과 빈 답변 칸을 만들 수 있다. 사용자가 적은 질문·답변·메모는 원문 그대로 보존하며 지우거나 요약문으로 바꾸지 않는다. 기존 Q#와 답의 연결을 유지하고, 사용자가 질문을 고쳤으면 실제 문구를 따른다. 예문과 빈 답변 칸은 답으로 처리하지 않는다. 추가 대화는 AI가 기존 질문에 연결하거나 새 Q#를 붙인다. 사용자에게 표·번호 작성을 요구하지 않는다.
